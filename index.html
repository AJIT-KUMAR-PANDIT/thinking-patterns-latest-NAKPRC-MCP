Generate LLM Thinking Patterns for Any Project

Analyze architecture, directory structure, dependencies, and frameworks — then generate comprehensive reasoning frameworks that help AI assistants understand codebases.

🔍 What It Detects

Automatically identifies your project's stack, structure, and conventions in a single command.

🏢

Architecture Analysis

Entry points, build systems, module resolution, framework layers, and source/dist roots.

📋

Structure Mapping

Directory hierarchy, file distribution, language breakdown, and complexity indicators.

🧭

Framework Detection

React, Next.js, Vue, Angular, Svelte, NestJS, Express, Django, FastAPI, and 30+ more.

📝

Language Distribution

TypeScript, JavaScript, Python, Rust, Go, Ruby, and 20+ languages with file counts and line weights.

🧦

Codebase Metrics

Total files, lines, size, max depth, test coverage, linting, TypeScript, and health indicators.

🔗

MCP Server

Integrated MCP server with 3 tools: analyze_project, get_thinking_patterns, get_project_summary.

📦 Install

Choose your preferred method. No build step needed.

🎮 npm (Recommended)

npm install -g nakprc-thinking-patterns

Install globally. Then run nakprc tp start in any project directory.

⚡ npx (No Install)

npx nakprc-thinking-patterns tp start

Run directly without installing. Downloads on first use, cached thereafter.

📈 Clone & Run

git clone https://github.com/AJIT-KUMAR-PANDIT/thinking-patterns-latest-NAKPRC-MCP
node nakprc.js tp start

Run locally from source. Zero setup, no package manager needed.

📊 Usage

One command. Full project analysis. Output as formatted text, JSON, or file.

terminal
$ cd /path/to/your/project
› nakprc tp start

🤖 MCP Server Mode

Integrate with Claude Desktop, Cursor, or any MCP-compatible tool. Three tools exposed via stdio.

Configure in your MCP settings:

{ "mcpServers": { "nakprc-thinking-patterns": { "command": "nakprc", "args": ["mcp"] } } }

Available tools:
analyze_project — Full project analysis
get_thinking_patterns — Get patterns by section
get_project_summary — Quick summary
